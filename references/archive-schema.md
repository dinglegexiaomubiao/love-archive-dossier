# 恋爱档案 · section 规范

本 skill 只产出一个文件：**恋爱档案-（对方）.html**，由 6 个 section 合并而成。
每个 section 是一个独立 HTML 文件（AI 在分析阶段填充），`merge_dossier.py` 抽取其 `<body>` 统一包装。

> 设计原则：**一份文件装下全部复盘**。双向画像、争吵全景、逐场深析、冲突深描、主题深描合订为同一份 HTML，便于断网查看、打印与单文件归档。

## 可用的版式组件（CSS class，已在合并外壳定义）

| 组件 | 用法 | 适用 |
|---|---|---|
| `.cover`（自动生成） | 封面：字距 kicker + 衬线大标题 + 副标 + 注脚，由 dossier.toml 的 kicker/title/subtitle/intro 生成 | 不用手改 |
| `.toc`（自动生成） | 暖色编号目录，由 6 段 nav/title 生成 | 不用手改 |
| `.scene`（自动生成） | 分节外壳：衬线序号 + 衬线标题 + 注脚，由 section 的 title/desc 生成；内容写进 section body | 不用手改 |
| `.stat` + `.grid` | `<div class="grid"><div class="stat"><div class="n">数值</div><div class="l">标签</div></div>…</div>` | 量化速览卡 |
| `.card` / `.card.blue` / `.card.pink` | 卡片；blue=我方，pink=对方 | 双向画像、结论 |
| `.cols` | 两栏并排 | 双方对照 |
| `.quote` / `.quote.u`（蓝=我）/ `.quote.l`（红=对方） | 引用原话 | 双向还原、逐句质证 |
| `.ev` | 证据表（th 红底，第2列我、第3列对方底色） | 指责逐条裁决表 |
| `.fight` | `head`（日期/主题/强度）+ `body`（触发→升级→转折→收尾） | 单场吵架 |
| `.bar-row` / `.bar` / `.bar.blue` | 横向条形（月度频率、升级方占比） | 全景量化 |
| `.badge` `b-own/b-part/b-proj/b-u/b-l/b-both` | 归属徽章 | 归因四分类 |
| `.own`/`.proj`/`.good` | 我方责任/对方责任/共同（绿）底色块 | 归因四分类 |
| `.summary` | 渐变高亮块 | 段落小结 / 一句话结论 |
| `.rule` | 左金边规则块 | 规律总结 |
| `img.chart` | 图表（base64 内嵌，白底圆角） | 可视化 |
| `.hl`(金) / `.hlred`(红) / `.hlgreen`(绿) | 高亮词 | 强调 |

## 六段必含内容

### 1 · 双向用户画像（锐评版） `1_双向画像.html`
- **数据速览卡**（`.grid`+.`stat`）：总条数、天数、我/对方条数比、日均、亲密期峰值月。
- **我（.card.blue）** 与 **对方（.card.pink）** 各一张：基本信息、沟通风格、喜好/口头禅、优点、缺点；量化部分（字长、emoji、活跃时段、高频词）取 `metrics.json`。
- **对比**：话题/语气/情绪用 `.bar-row` 或并排 `.card`。
- **结论回写占位**：`dossier.toml` 的 inject 会把深描结论补进此处。

### 2 · 关键争吵 · 全景与类型学 `2_争吵全景.html`
- 来自 `out/conflicts.json`：总段数、强冲突段数、双方「谁先升级」占比。
- 月度频率（`.bar-row`）、升级方占比（`.bar.blue`）。
- **六类类型学**（示例，按需调整）：爱意计量 / 家人尊重 / 双标回旋镖 / 道德绑架 / 误读投射 / 亲密边界。每类一两句 + 代表日期。
- 关键论点结构（ADU：claim/counterclaim）可放一两场示例。

### 3 · 关键吵架深度分析 `3_吵架深析.html`
- 选 5–8 场关键吵架，每场一个 `.fight`：
  - `head`：日期 · 主题 · 强度 · 谁先升级
  - `body`：触发 → 升级 → 转折点 → 收尾；标注重伤词/转折词。
- 末尾 `.rule` 总结跨场规律（谁更常先升级、收口方式、反复出现的雷区）。

### 4 · 关键冲突事件深描 `4_冲突深描.html`
- 点名 2–4 个最撕裂的事件，**双向逐句还原**（`.quote.u`/`.quote.l`）。
- 每事件给「我方责任 / 对方责任 / 共同责任 / **非任何人责任**」四分类（`.own`/`.proj`/`.good`/`.badge`）。最后一类必须填，否则不合格。

### 5 · 主题深描 · 价值感/物化/既要又要/道德绑架 `5_主题_价值感.html`
- 对「用户提出的具体观察」回库搜原句，逐条 **坐实 / 证伪**（`.ev` 表）。
- 强判断词（PUA、没逻辑）一律「观察 + 证据」呈现，不凭空定罪。

### 6 · 主题深描 · 家族与指责辩析 `6_主题_家族.html`
- 还原某次具体指责原文，列证据表逐条裁决（坐实/部分/需打折），回写画像。

## 写作纪律（硬性）
- **平视**：写「他做了 X，她做了 Y，X 和 Y 撞在一起产生 Z」，不写「他很自私」。
- **证据挂回**：每个判断后面能填出时间戳或统计值；动机标「推断」。
- **双向裁决**：任何一方的指控都要能反向裁决，避免单方定罪。
- **诚实三件事**：数据缺失、推断而非事实、即使改了也未必能挽回。
- **归因四分类**：我的责任 / 对方的责任 / 共同的责任 / **不是任何人的责任**（末行空着不合格）。
- **不站队、不定罪、不替读者下「爱与不爱」的定论**。
