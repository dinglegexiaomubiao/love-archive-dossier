# 恋爱档案 · 深度分析方法

> 来源：两段真实关系（约 5.5 万条与约 18 万条）的完整实践，沉淀为可复用的恋爱档案 SOP。
> 目标：用统一口径把一份聊天记录做成「一份装得下的关系全档案」。

---

## 0 · 全链路（6 步，只出一份 HTML）

```
① 取数        wechat-chat-export 严格导出（坏页加 --tolerant）→ 聊天记录.json
② 指标        collect.py -c config.toml            → out/metrics.json（全量可比口径）
③ 冲突检测    detect_conflicts.py -c config.toml   → out/conflicts.json（冲突时段 + 谁先升级）
④ 精读定位    三筛子（拐点/关键词/首尾）+ 指责句式词典，定位 6–10 个事件（每个有日期+原话）
⑤ AI 写 6 段 按 references/archive-schema.md 填充 1_双向画像 ~ 6_主题_家族 六个 HTML
⑥ 合并        solo_pipeline.py build               → 恋爱档案-（对方）.html（单一自包含网页）
```

`solo_pipeline.py init` 一次性完成 ①②③ 并生成 ④ 的草稿骨架；⑤ 由 AI 填充；⑥ 合成单文件。

---

## 1 · 口径（跨档案固定，改了不可比）

| 项 | 值 | 备注 |
|---|---|---|
| 会话切分 | 相邻间隔 > 4 小时 | config `[stats]` |
| 回复延迟 | 剔除 > 24 小时中断 | config `[stats]` |
| 情绪词表 | 固定 `[emotion]` | config `[emotion]` |
| 词频 | 仅文本、剔除停用词、取 `[↩` 前自身内容（引用消息 XML 污染） | 见坑 3 |
| 冲突检测 | TIER1×4 / TIER2×2 / TIER3×1，相邻命中 > 3h 新段；强度≥6 且≥15min，或命中≥4 | detect_conflicts.py |
| 字数 | 去空白后字符数 | 成册规范 |
| 时区 | UTC+8 | 双链路 |

---

## 2 · 精读三筛子（不要通读全文）

1. **拐点**：数据突变那天（用**绝对增量** delta，不用倍数）。
2. **关键词**：按主题分组（关系确认/见面/冲突/家庭/礼物），命中处取前后各 2 条一起看。
3. **首尾**：第一句、最后一句、最长沉默期前后。
4. **指责句式词典**（补）：`你总是/你根本/你凭什么/你从不…` 批量抽「互相指责句」，比情绪词更精准定位互怼。

验收：能说出 6–10 个具体事件，每个都有日期和原话。

---

## 3 · 两份镜像锐评（关键的「不站队」机制）

不是单方面骂一方，而是**互为原被告、各出一份**（写在 section 3/4/5 里）：
- 据对方的指责锐评「我」：把她的指控裁决为 **该认的 / 部分成立 / 她的投射**；
- 据我的指责锐评「对方」：把我的指控裁决为 **坐实 / 部分坐实 / 需打折**。

每条裁决 = 你的观察 + 聊天原文证据 + 数据。强判断词一律「观察 + 证据」呈现，不凭空定罪。

---

## 4 · 主题深描（观察驱动，回原文取证）

用户提出具体观察（如「她在物化自己又当又立」「她的『我的思维没有那么局限』很变态」）→ 回库搜原句 → 逐条坐实/证伪 → 回写画像（section 5/6）。

用 `.ev` 证据表逐条裁决，比纯叙述可信。

## 6 · 踩坑清单（必看）

1. **合并转发第三方 sender 污染统计**：`collect.py` 展开 `forwarded_messages` 后，第三方 sender（群成员/被转发者）会进入 `sessions.initiator`/月度/年度，并把关系起点伪造。→ config 默认 `strict_parties=true`，只保留 me/other/系统 三方；转发内第三方消息仍可内容分析但不计入双方对比。
2. **坏页一票否决**：微信 `message_0.db` 第 262145 页常固定损坏，导出务必加 `--tolerant`，否则全库中止。档案第 1 节「完整性」必须如实写明。
3. **引用消息 XML 污染词频**：引用 `content` 会附带被引用原文（小程序/卡片/名片带 `appmsg/aeskey/wxid_` 垃圾）→ 分词/情感只取 `[↩` 之前说话人自己的文本。
4. **时间戳毫秒/秒混用**：`if value > 1e11: value //= 1000`。
5. **合并时直接拼接各文档 CSS**：字号/栏宽跳变 → `merge_dossier.py` 统一外壳 + 抽 body，不再拼接源 CSS。

## 7 · 写作纪律（来自 skill）

- **平视**：写「他做了 X，她做了 Y，X 和 Y 撞在一起产生 Z」，不写「他很自私」。
- **证据挂回**：判断后括号能填时间戳或统计值；动机标「推断」。
- **双向裁决**：任一方指控都要能反向裁决。
- **诚实三件事**：数据缺失、推断而非事实、即使改了也未必挽回。
- **归因四分类**：我的责任/对方的责任/共同的责任/**不是任何人的责任**（最后一行空着不合格）。
- **敏感度**：私密内容集中、交付时提示明文风险、不要主动建议分享。
